01🤔 what i think about code

  
    
    
  1. ievery line is context.
    clean code can sound like a standard from old style books, but agents build on whatever is already there. if the base is strong, so is everything built on it: better code is better context for every agent that touches it next. (on clean code, the same agent used 7% fewer tokens and re-opened files 34% less.)
    2. 
    
  2. iireduce, reuse, recycle.
    it belongs in code too: reuse what's already there, add an abstraction only when it earns its place, and name things so they can be found again.
    3. 
    
  3. iiiless code isn't always better code.
    deleting and reusing can go too far. ten screens sharing one api call looks tidy, until that call does heavy backend work and each screen throws most of it away. so skrub only deletes on its own what knip finds unused, then runs the typecheck and puts back anything that broke. anything that needs judgment, like a duplicate or a wrapper that looks pointless, it hands to you.
    4. 
    
  4. ivthe repo's habits beat anyone's taste.
    models keep changing and getting better. i can't write better code than a frontier model, but i can give it a baseline: the conventions this codebase already follows, read from the code itself.
    5. 
    
  5. vif a tool can check it, it doesn't belong in a prompt.
    a rule in a CLAUDE.md is a request, not a guarantee: across 481 of those files, only 4.4% of the security rules had anything actually enforcing them. so skrub turns what it can into checks, and leaves the writing for judgment calls.
    6. 
    
  6. vibuild like a product engineer.
    the best code is the change the user actually needed. before it builds, the agent works out the problem behind the ask, and copies what's conventional in its space: for a devtool, how sentry, braintrust or posthog do it. users already know those patterns, so they don't have to learn yours.
    7.

export function toCsv(report: Report): string {
  const head = report.columns.map(escapeCell);
  const body = getRows(report).map(formatRow);
  const totals = sumColumns(report);
  const foot = report.columns.map((column) => String(totals[column] ?? ""));

function sumColumns(report: Report): Record<string, number> {like columnTotals
  const sums: Record<string, number> = {};
  for (const column of report.columns) {
    sums[column] = report.rows.reduce((total, row) => {
      const value = row.values[column];
      return typeof value === "number" ? total + Math.round(value) : total;
    }, 0);
  }
  return sums;
}
